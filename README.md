# E-Commerce Customer Segmentation Using RFM Analysis

## Business Problem
Segment customers based on purchasing behavior.

## Dataset
4395 transactions
681 customers

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

## Customer Segments
- VIP Customers
- Loyal Customers
- Occasional Customers
- Lost Customers

## Business Recommendations
- Retain VIP customers
- Re-engage lost customers
- Reward loyal customers
